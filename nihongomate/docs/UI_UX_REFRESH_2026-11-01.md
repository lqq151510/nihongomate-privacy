# 界面与学习体验优化 · 2026-11-01

本轮基于现有 Vue / Capacitor 应用做增量优化。所有题库、课程内容、学习记录格式及音频工具保留；未提交、推送或发布。

## 已实现

- 手机保留底部五项导航；900px 以上改为侧边学习导航和宽屏内容区域。统一 Lucide 线性图标、选中态、品牌标题和打卡入口。
- 分级学习整理为等级选择、学习内容切换和课程正文三个层级；N5–N1 等宽展示，按钮提供 `aria-pressed`，主导航提供 `aria-current`。
- 采用浅樱花粉、深玫瑰、墨蓝及白色；欢迎卡使用淡假名水印，移动端压缩为一行，优先留出学习操作空间。
- N5 及 N4–N1 系统课提供真实已完成单元进度、可展开课程说明和六项段落跳转：词汇、句型、听力、阅读、练习、表达。
- 跳转按当前实际吸顶栏高度避让并转移键盘焦点；600px 以下短屏取消吸顶，避免工具栏占满阅读区；遵循减少动画偏好。
- 系统课程正文 14px；提高已有小字字号。主内容按钮最小高度 44px，课程朗读按钮最小宽度 44px；文字可选择复制。
- 练习模式切换改为可横向滚动的标签栏，缩短“即时练习”标签，避免五等分长文字挤压。
- 为条件出现的操作提示分配独立网格区域，避免提示挤入侧栏或底部导航之后。
