本地学习与可选多人功能隐私说明

《随身日语伴侣》隐私政策

开发者：刘勇泽 | 应用包名：com.zebao.nihongomate | 更新及生效日期：2026年11月1日（2026-11-01-social-cloud-voice）

🛡️当前版本使用说明
  • 无需注册：课程和练习以游客方式使用；可选“搭子”功能提供独立用户名账号，不提供手机号验证码登录。
  • 本地保存：学习记录、目标、昵称、简介和您自选的头像保存在当前设备。
  • 设备朗读：语音合成由设备提供，是否联网取决于您使用的语音引擎及语音包。
  • 可选多人功能：主动配置服务、勾选联网说明并注册或登录后，在线资料、好友关系、自习室及消息由该服务处理。学习进度和本地头像不会自动上传。
  • 当前无商业化 SDK：本版本未接入广告、支付或用户行为分析 SDK。

一、引言与适用范围

本政策适用于由刘勇泽开发维护的《随身日语伴侣》当前包含本地学习及可选多人功能的开发版本。我们按实际功能说明数据处理方式。您可在首次提示中选择“仅使用本地功能”继续学习，也可随时在设置中阅读本政策及重新选择。未来如接入广告或支付等其他服务，将另行说明其数据处理规则，不以本次选择代替未来所需的授权。

二、数据与使用目的

场景数据用途与处理方式
学习与练习单词掌握程度、复习时间、错题、语法练习结果、模拟考场的答卷与计时状态、打卡、统计、学习目标通过 LocalStorage 保存到本机，用于恢复进度及安排复习；本应用不向开发者服务器同步这些记录。
可选个人资料昵称、简介、自选照片或预设头像、本地资料标识仅供当前设备展示。您主动选择的照片在本机居中裁剪并保存，不上传服务器；资料标识不用于身份认证。
日语朗读您播放的课程或题目中的日语文本、选择的音色和语速音色和语速偏好保存在本机；播放文本通过 Web Speech API 交给设备提供的语音合成服务。设备引擎可能需要语音包或网络服务，其数据处理还受对应提供方规则约束。本应用不保证所有设备均可离线朗读。选择“仅使用本地功能”时，仅调用系统标记为本地服务的日语音色（localService）；没有该音色时不会开始朗读，文字课程不受影响。该标记由系统提供，本应用无法独立审计系统语音引擎。
可选在线账号与搭子用户名、密码、在线昵称、学习级别、简介、允许发现的选择仅在您主动开启联网后传到所配置服务；服务保存密码的安全哈希，不保存明文密码。发现默认关闭；允许发现时昵称、用户名、级别和简介对登录用户可见，其他登录用户仍可用完整用户名精确查找您。在线资料与本地资料独立。
好友与自习室讨论好友申请与关系、自习室、成员、邀请码、文字消息及发送时间由所配置服务保存，用于跨会话同步。好友须对方同意；公开房间的标题、说明、级别与人数对登录用户可见；私密房间通过邀请码加入；房间消息仅成员可读。服务运营者可管理其数据库。请勿在简介、房间或消息中填写敏感信息。
隐私选择政策版本与“同意”或“仅本地使用”的选择保存在本机，避免重复提示；新政策版本会重新提示。

本版本不要求输入手机号、身份证号、银行卡号，不主动访问通讯录、短信、精确定位或设备唯一标识。选择头像时由系统文件选择器提供您选中的图片，本应用不主动扫描整个相册。朗读、选择照片等可选操作不影响文字课程的使用。

若设备上保留了旧版本模拟登录数据，升级后会移除其中的手机号、模拟短信记录及模拟登录状态，保留昵称、头像、简介与学习记录。旧模拟登录不构成真实账号，也没有云端账户可供恢复。

三、本地存储与相关技术

本应用使用 LocalStorage 保存本地资料、学习记录及所选服务地址，使用 SessionStorage 保存当前在线登录会话令牌；不在本机存储中保存密码，不接入跨站广告跟踪或用户行为分析服务。清除应用数据、浏览器站点数据或更换设备可能导致记录丢失；本地学习记录没有云同步；在线好友和房间数据在连接同一服务并登录同一账号后从服务读取。

四、第三方服务与信息传输

当前版本未接入商业广告、支付、短信认证或行为分析 SDK。可选社交请求发送到您明确配置的服务，服务会收到网络连接所需的来源 IP。多人功能通过所配置的 HTTPS 学习服务处理在线资料、好友关系、自习室与文字消息；手机仅连接可信的 HTTPS 服务，HTTP 仅用于电脑本地开发。日语朗读调用设备提供的语音合成服务，具体声音及联网能力因设备而异。您主动通过邮箱向开发者反馈时，邮件内容由您选择的邮件服务传输，并由开发者用于回复与处理该反馈。请不要在反馈中发送密码、身份证号等无关敏感信息。

可选的 Azure 联网多音色默认关闭。您单独开启后，朗读文本、音色、语速和音高会发送到您配置的语音服务，再由服务请求 Azure；可能产生网络及服务费用。Azure 密钥仅保存在服务端，应用只在本机保存服务地址和访问口令。选择“仅使用本地功能”会阻止联网朗读。语音服务采用有界音频缓存以减少重复请求，不会自动上传学习进度、头像或个人简介。请求与故障日志不应记录密钥或朗读文本。

五、存储、备份与删除

学习记录和可选个人资料主要保存在当前设备的应用存储中，直至您主动清除。设备操作系统可能按其备份设置备份或恢复应用数据，其行为取决于系统配置。清除或卸载应用不代表系统备份副本已同步删除，也不承诺物理不可恢复的销毁。

请妥善保护设备。LocalStorage 不用于保存密码、支付凭据或其他高敏感信息；当前版本没有开发者提供的云端学习备份。在线数据保存在配置服务的 SQLite 数据库，保留到服务运营者清除；退出登录会撤销当前服务端会话。关闭联网或清除浏览器数据不会自动删除服务端账号、好友或历史消息。本地开发版尚无自助账号注销或消息撤回入口，需联系服务运营者按数据库备份与删除流程处理，公共部署前应补齐相应管理能力。

六、您的管理方式

  • 查阅与更正：在设置查看统计，编辑本地昵称、简介和头像。
  • 清除资料：设置中的“清除本地个人资料”恢复默认昵称、头像和简介，保留学习记录。
  • 清除学习：设置中的“清除本地学习记录”清除单词掌握、复习、错题、打卡等记录，保留个人资料。
  • 重新选择：通过设置打开完整隐私政策后，可重新选择本地使用方式。选择“仅使用本地功能”或在搭子页关闭联网，会停止社交请求并清除本机当前登录会话，但不会删除服务端数据。服务端资料删除请联系该服务运营者；如需管理系统备份，请使用设备系统提供的设置。

七、未成年人使用

建议未成年人在监护人指导下使用学习功能，并避免在可选昵称、头像、简介或反馈邮件中填写不必要的个人信息。本版本不提供充值、付费会员或广告。

八、政策更新

我们会在功能及数据处理方式变化时更新政策版本和日期，并通过应用提示重新告知。需要授权的新服务会在获得相应选择后启用。当前的本地使用选择不构成对尚未接入服务的授权。
